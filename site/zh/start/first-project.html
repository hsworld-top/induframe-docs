创建第一个工程 ​

本教程的目标是：创建一个自己的工程，完成源码初始化，并在开发工作区看到预览。正式发布和运行需要后续步骤。

开始前，平台应已安装、组织可正常登录，你使用的是有工程功能权限的组织账号。开发环境的部署和资源由平台管理员事先准备；本教程不要求在个人电脑另装数据库或容器。

1. 进入工程管理 ​

从公共入口选择正确组织并登录，打开“工程管理”。

没有工程管理入口时，先让组织管理员确认角色。显示读取失败时先重试，不把空白画面当成需要重新安装平台。

2. 新建一个工程 ​

点击 “新建工程”，输入便于识别的名称，例如“我的第一个工程”；这是示例名称，请按实际情况填写。描述可以简单写明用途。

点击 “创建”，等待成功，在工程列表确认新工程。请求结果不明确时先搜索核对，不连续新建同名工程。

新工程默认私有；需要同组织协作时，再按工程管理确认共享范围和权限。

做到这里：工程记录已经存在，但源码可能还未初始化。

3. 打开应用开发并选择模板 ​

在这个工程打开 “应用开发”。若系统已自动打开，直接继续。

第一次会看到“选择工程技术栈”，提供 Vue、React 与 JavaScript、TypeScript 的模板组合。按团队安排选择；没有约定时先确认页面选项，再点击该页面的 “创建工程”。

这里是在已有工程里生成初始源码，不是再次在组织中创建同名工程。初始化完成后，不通过反复重选模板切换技术栈。

做到这里：工作区能够显示 AI、编辑器和页面等工具。暂未就绪时等待服务状态，不反复启停。

4. 保存修改并查看页面 ​

进入“编辑器”查看源码，或通过 AI 协助修改。保存更改后，选择 **“页面”**查看预览；需要时按提示启动预览服务。

第一次使用 AI，先看AI 助手操作说明，确认模型、工具范围和任务，再检查实际修改。

页面需要登录或数据权限时，使用合适的工程用户。预览工具的身份选择与组织登录不同，详细操作见预览工程页面。

做到这里：能够看到当前工程的开发页面，并知道怎样保存和检查更改。仍需按用途核对实际交互与数据结果。

5. 结束这次操作 ​

保存未保存内容。需要暂停整个开发环境时，先通知共同使用者，再按工作区说明确认停止；只想重新加载画面时用预览“刷新”。

不要用删除工程代替停止开发环境。

接下来做什么 ​

  • 需要管理其他工程、标签或分组：看创建和管理工程。
  • 需要上传资料：看查看和上传工程文件。
  • 需要接入业务数据：从认识数据中心开始。
  • 准备正式使用：先理解开发、发布与运行，再按交付安排完成相应配置和部署。

遇到配额、权限、初始化或预览错误时，保存工程名称和页面提示，请管理员核对；不要为绕过错误关闭安全检查或删除已有工程。
