安装并进入平台 ​

这条教程带你在准备好的 Linux 服务器上安装 InduFrame 中心，随后通过浏览器进入默认组织的工作台。完成后，你应能登录、打开工程管理、刷新页面并正常退出。

你需要服务器的系统管理权限、匹配架构的完整安装包，以及能够访问服务器的浏览器。首次安全设置由平台超级管理员完成，组织管理员随后从公共入口登录。若平台已经安装并完成设置，可直接阅读登录与退出。

1. 准备服务器和访问地址 ​

先核对安装前准备：操作系统、剩余磁盘空间、访问地址、端口和证书。保留完整安装包，确认目标服务器就是本次安装对象。

完成标志：安装所需材料齐全，浏览器可以到达计划使用的服务器网络。

2. 安装中心 ​

在完整包目录执行安装入口，按提示填写存放位置、公共地址、端口、平台超级管理员和证书配置。具体步骤与默认值见安装中心。

完成标志：终端显示“InduFrame 中心安装完成。”，安装进程正常结束，并给出公共入口、管理入口和日志路径。

3. 完成首次设置 ​

从管理入口登录，在“组织管理”为默认组织管理员设置密码，再打开公共入口。两个入口的操作见完成首次设置。

完成标志：出现“管理员密码已重置”反馈，公共入口开放，组织管理员能使用新密码登录。

4. 确认安装成功 ​

按确认安装成功核对终端、管理入口和组织工作台。打开工程管理，刷新后确认仍可访问，再退出并确认受保护页面需要重新登录。

完成标志：这些检查都有明确结果。工程部署还需要单独准备运行环境的基础服务，安装完成不代表工程已经投入运行。

遇到问题 ​

停在当前失败步骤，保留提示和时间，根据安装常见问题先核对可观察条件。未出现安装完成提示时，不要直接转入首次设置，也不要以删除数据或反复重装代替排查。

下一步 ​

保存两个入口地址与账号交接信息，日常使用从登录与退出开始。需要停用时，先了解卸载平台中两种方式对数据的影响。
