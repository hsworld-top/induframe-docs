安装中心 ​

本页安装的是 InduFrame 的平台中心，装好后就可以从浏览器打开它。当前版本为 v1.0，优先使用已测试的 Ubuntu 24；其他系统尚未测试。

已有平台时看更新已有平台；曾保留数据卸载时，按保留数据后重新安装操作。简短步骤见快速安装。

开始前 ​

完成安装前准备，备好完整安装包、服务器账号、公共地址和自己设置的平台管理员密码。安装需要系统管理权限，不熟悉服务器操作时请维护人员陪同。

1. 运行安装向导 ​

打开连接到服务器的终端，进入完整安装包解压后的文件夹。可先运行 ls，确认其中有 install.sh，再执行：

sh
./install.sh

若提示输入系统密码，输入当前服务器账号的密码。它用于取得安装权限，与稍后登录平台的密码不同。

一开始就出现 1) 更新、2) 取消，表示服务器上已有平台。没有更新计划时，输入 2 或回车取消，不要继续按首次安装操作。

2. 按提示填写信息 ​

向导一次问一项，方括号内是默认值。确认默认值适合你时，直接回车。

看到的提示建议怎样填写
选择存放位置没有特殊要求时回车使用 /opt，程序会放在 /opt/induframe
公共访问地址或域名填组织成员能访问的服务器 IP 或域名，不填 https:// 或网页路径
公共访问端口没有冲突时回车使用 443
管理入口端口没有特殊安排时回车使用 18100，不能与公共端口相同
平台超级管理员用户名没有特殊要求时回车使用 admin

不知道公共地址是否正确、或提示端口被占用时，先请维护人员核对，不要随便换地址或停止其他服务。

3. 选择证书并设置密码 ​

当向导询问 TLS 模式：

  • 没有专门准备证书：直接回车，使用默认 self-signed，由安装器生成证书。
  • 维护人员已准备好证书：按其安排选择 provided，填写证书、私钥等文件的完整路径。

使用默认方式后，浏览器可能显示证书信任提醒。请维护人员核对地址和证书后处理，不要关闭安全校验来继续。

随后按提示输入两次平台超级管理员初始密码。建议使用 8–72 个英文字母、数字或半角符号，输入通常显示为星号。两次不同或长度不合适时，在当前步骤重新输入。

妥善保管这组账号。全新安装后，它用于管理入口，无需再改一次初始密码。完整字段限制见安装参数。

4. 核对信息并等待完成 ​

向导会汇总程序目录、两个入口和管理员用户名，并显示日志路径。看一遍，确认与准备的信息一致。

安装分 14 个阶段准备运行环境、安装程序并检查服务。保持终端连接，不要同时再启动一轮安装。

看到替换或删除提示时先确认

服务器已有运行环境时，安装器可能询问是否替换，其中其他服务和数据也可能被删除。不清楚原有用途时，请停止并询问维护人员，不要为了继续安装直接同意。

怎样确认装好了 ​

同时确认以下三项：

  1. 14 个阶段已完成，最后是“检查服务状态”。
  2. 出现 “InduFrame 中心安装完成。”，安装命令没有报错并正常结束。
  3. 列出公共入口、管理入口和本次日志路径。

只看到阶段编号走到最后，还要等最终完成提示。安装人员核查命令退出状态时应为 0。

保存两个完整地址，以后直接复制到浏览器：

地址给谁使用
公共入口组织成员日常登录，使用 HTTPS，默认端口 443
管理入口平台超级管理员使用，当前是内网 HTTP 地址，默认端口 18100，带 /admin/

不要把管理入口替换成公共入口，也不要擅自改协议。日志通常在程序目录的 logs 文件夹，以终端打印路径为准。

更新已有平台 ​

  1. 向交付人员确认新完整包适用于当前平台，安排暂停使用并完成需要的备份。
  2. 将新包解压到另一个文件夹，进入后执行 ./install.sh。
  3. 出现 1) 更新、2) 取消 时，输入 1 才更新；输入 2 或回车取消。确认前已有平台保持原状。
  4. 更新沿用原安装位置、访问设置和账号。等待最终完成提示，再用原账号检查两个入口及实际业务数据。

本页不保证任意旧版本都能直接更新。出现数据结构不一致等错误时，保留提示和日志，请交付人员处理。

完整安装包没有单独的 update.sh；只有明确拿到小型补丁包时，才按其说明运行 ./update.sh。

失败或中断时 ​

记录最后阶段、完整提示和日志位置，先看安装常见问题。需排查时按提示保留设置和现场。

没有完成提示时，不要继续首次设置，也不要自行删除数据、安装记录或反复重装。保留设置只是方便排查，不表示已经安装成功。

下一步 ​

继续完成首次设置，为默认组织管理员设置密码，再按确认安装成功检查浏览器访问。
