安装中心 ​

目标 ​

在已准备好的服务器上完成 InduFrame 中心安装，取得公共入口、管理入口和安装日志位置。

角色与环境前提 ​

由具备服务器系统管理权限的安装人员操作。先完成安装前准备，准备匹配服务器架构的完整安装包，以及证书和平台超级管理员信息。

本页说明首次安装的详细步骤。已有平台需完整更新时，使用新完整包的同一入口，见本页更新已有平台；已经保留数据卸载的平台应改按保留数据后重新安装操作。需要随包离线阅读的简短步骤，可使用快速安装。

操作入口 ​

在服务器交互终端中进入完整安装包解压后的目录，执行包内安装入口。

sh
./install.sh

安装器会请求系统管理权限；需要时输入当前服务器账号的系统密码。该密码与稍后设置的平台超级管理员密码用途不同。

安装和完整更新均无需参数；查看帮助可执行 ./install.sh -h。如果检测到本机已完成安装，终端会先让你选择 1) 更新 或 2) 取消；输入 2 或直接回车均取消。确认更新前不会改写已有平台的程序、配置或安装记录。未完成的初次安装继续按原失败恢复流程处理，不会仅因存在安装文件就直接进入更新。

安装步骤与字段 ​

1. 填写程序位置和访问入口 ​

按终端顺序填写以下字段，使用默认值时按回车。

终端字段如何填写
选择存放位置默认 /opt，实际程序目录为 /opt/induframe；填写父目录，不要再手工追加 induframe
公共访问地址或域名填写组织成员可以访问的地址；确认默认地址适合使用后才直接回车
公共访问端口默认 443，当前公共入口固定使用 HTTPS
管理入口端口默认 18100，管理地址由安装器自动选择服务器内网地址
平台超级管理员用户名默认 admin，用于稍后登录管理入口

程序位置必须是可用的绝对目录，不得位于安装包内部或经过符号链接。路径输入有误时，按终端提示在当前步骤重新填写。更多字段限制见安装参数。

2. 选择证书方式 ​

在 TLS 模式 处选择以下一种方式。

输入含义与后续字段
回车或 self-signed由安装器生成自签名证书，之后由维护人员核对浏览器信任
provided使用已准备的证书，依次填写证书文件、私钥文件的绝对路径，以及按需提供的 CA 文件路径

自带证书的覆盖地址、有效期和信任链须由维护人员提前核对。不要把证书文件内容直接粘贴到路径字段中。

3. 设置平台超级管理员密码 ​

在 平台超级管理员初始密码 和再次输入密码的提示中输入同一密码。输入内容会隐藏，通常以星号显示输入进度。

密码实际限制为 8–72 字节。建议使用 8–72 个 ASCII 字符，例如英文字母、数字和半角符号。终端虽然显示“字符”，但中文等字符占用多个字节；不要只根据显示字符数判断长度。长度不符合要求或两次输入不一致时，安装器会在当前步骤要求重新输入。

请保管好这组账号。全新安装成功后，平台超级管理员直接使用本次设置的密码登录，无需再次改密。

4. 核对安装前提示 ​

安装器可能提示准备缺少的系统网络组件，或替换服务器已有的运行环境。先看清提示中的操作及影响范围，再由有权管理该服务器的人员决定。替换已有运行环境会删除其中的服务和数据；不清楚现有用途时应停止并联系维护人员。

正式安装前，终端会汇总程序目录、公共入口、管理入口和管理员用户名，并显示安装日志路径。核对这些信息是否符合准备结果。

5. 等待全部安装阶段完成 ​

保持终端连接，等待安装器依次检查环境、准备程序、启动服务并检查状态。当前完整安装包含 14 个阶段，最后一个阶段为“检查服务状态”。等待时长不是完成百分比。

如果出现“安装未完成”、失败提示或连接意外中断，先按本页的失败处理保留信息，不要转入首次设置。

成功确认 ​

以下条件需要同时满足。

  • 终端显示完整的 14 个阶段均已完成。
  • 安装命令正常结束，退出状态为 0。
  • 终端显示“InduFrame 中心安装完成。”，并给出公共入口、管理入口和安装日志路径。

仅看到部分阶段通过，或浏览器暂时能打开某个页面，都不能代替这三项确认。

保存终端给出的两个完整地址。公共入口使用 HTTPS；管理入口使用内网 HTTP 地址，默认端口为 18100，路径包含 /admin/。不要自行将管理入口改成 HTTPS，或把它替换成公共地址下的同名路径。

安装日志位于程序目录的 logs 下，文件名为 install-*.log；以终端打印的本次日志路径为准。保留完整原安装包。

更新已有平台 ​

先安排暂停使用，并由维护人员完成所需备份。将新取得的完整安装包解压到独立目录，进入该目录执行 ./install.sh。检测到已完成安装后，输入 1 确认更新；输入 2 或回车取消。

更新沿用原安装位置、访问设置和账号，保留平台数据。等待最终完成提示及命令正常结束后，用原账号核对公共入口、管理入口及所需工程。更新保留数据不表示支持任意旧数据结构；遇到数据结构不一致或其他失败提示时，保留日志并联系维护人员。

完整安装包不提供单独的 update.sh。只有交付人员明确提供小型补丁包时，才使用补丁包内的 ./update.sh；补丁与当前安装不匹配时应停止，并由交付人员提供适用的完整包。

失败或中断时 ​

记录最后显示的阶段、提示和日志路径，并联系维护人员。若出现是否保留设置的提示，需要留下现场供排查时选择保留；保留设置不代表安装已完成，也不保证再次执行就能恢复。

不要直接删除平台目录、数据或记录，不要连续重新安装来试错。具体先查哪些信息，见安装常见问题。

下一步 ​

终端确认安装成功后，继续完成首次设置，再按确认安装成功检查浏览器入口和组织登录。
