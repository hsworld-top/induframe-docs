快速安装 ​

本页适用于 InduFrame v1.0。优先推荐 Ubuntu 24，这是目前已测试的系统；其他系统尚未测试。 不确定系统或安装包是否合适时，先请交付人员确认。

安装前 ​

将适用的完整安装包上传到服务器并完整解压，不要只取出其中的脚本。服务器账号需要有系统管理权限，也就是能够使用 sudo。

系统盘和另行使用的数据盘，都须同时保留至少 30 GiB 且 20% 的可用空间，另为业务数据增长预留容量。准备好组织成员能访问的服务器地址，以及自己设置的平台管理员密码。

不会连接服务器、上传文件或进入安装包文件夹时，可先请服务器维护人员协助。

安装 ​

在服务器终端进入解压后的安装包文件夹，确认其中有 install.sh，再执行：

sh
./install.sh
  1. 如果询问系统密码，输入当前服务器账号的密码，不是平台登录密码。
  2. 按向导填写安装位置、访问地址和端口。默认位置为 /opt，实际程序目录为 /opt/induframe；公共端口默认 443，管理端口默认 18100。采用默认值时直接回车。
  3. 没有专门准备证书时，在证书方式处回车使用默认的 self-signed；有现成证书文件时，再由维护人员选择 provided。
  4. 设置平台超级管理员用户名和密码。默认用户名为 admin；建议密码使用 8–72 个英文字母、数字或半角符号，并输入两次。
  5. 保持终端连接，等到 “InduFrame 中心安装完成。”、命令正常结束，并列出公共入口、管理入口和日志路径。

保存这两个完整地址。先打开管理入口，以安装时设置的平台账号登录，在“组织管理”为默认组织重置管理员密码；再从公共入口用组织管理员账号登录。

详细步骤见安装中心和完成首次设置。浏览器提示证书不受信任时，先请维护人员核对地址与证书，再处理信任。

更新 ​

先向交付人员确认新完整包适用于当前平台，安排暂停使用和备份。将新包解压到另一个文件夹，进入后仍执行：

sh
./install.sh

出现 1) 更新、2) 取消 时，输入 1 才更新；输入 2 或直接回车取消，确认前已有平台保持原状。

更新沿用原安装位置、访问设置和账号。等待最终完成提示后，用原账号检查两个入口及实际业务数据。不要自行尝试未经确认的跨版本更新。

只有交付人员明确提供小型补丁包时，才按补丁说明运行其中的 ./update.sh；完整安装包统一使用 ./install.sh。

卸载 ​

先通知使用者，决定是否保留数据。在完整安装包文件夹执行：

sh
sudo ./uninstall.sh

原包不在时，可用已安装的卸载脚本。默认位置是：

sh
sudo /opt/induframe/uninstall.sh
终端问到什么应怎样回答
是否确定卸载输入 y 继续；输入 n 或回车取消
是否同时删除平台数据与运行环境保留数据时输入 n 或回车；确定删除时才输入 y
输入 PURGE 确认只在确定永久删除时输入大写 PURGE

两次回车的含义不同：第一次是取消卸载，第二次是卸载服务并保留数据。 需要重装时，先看保留数据后重新安装的条件。

删除无法撤回。如果另行询问是否删除服务器原有运行环境，默认保留；不清楚其中是否有别的服务时，不要同意删除。

遇到问题 ​

保留终端完整提示和日志路径，先看安装常见问题。没有安装完成提示、或卸载显示未完成时，不要靠反复重装或手工删除目录试错。

若终端报告仍有采集数据或系统规则需要处理，交给维护人员核对；卸载结束不代表这些留存事项也已处理完。
