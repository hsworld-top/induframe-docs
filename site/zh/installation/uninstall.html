卸载平台 ​

卸载会停止平台服务，组织成员将无法继续使用。先通知使用者，确认你操作的是正确的服务器。

本页说明 v1.0 在已测试的 Ubuntu 24 上的卸载流程，其他系统尚未测试。

先决定：以后还要不要这些数据 ​

你的打算建议选择
暂时停用，或准备在原服务器重装保留数据卸载，保存原安装包、原账号和数据
确定不再需要平台及其数据确认备份和删除范围后，再选择删除数据
还没决定，或不知道数据是否有人需要先取消，与数据负责人确认

保留数据不是备份，删除数据无法撤回。 本版本没有一键完整备份还原工具，不要在未确认的情况下尝试删除后恢复。

准备重装时，先阅读保留数据后重新安装，确认所需条件。

1. 打开卸载程序 ​

让具备系统管理权限的维护人员，在服务器终端执行卸载脚本。默认程序位置可使用：

sh
sudo /opt/induframe/uninstall.sh

安装时选了其他位置，请替换为实际程序目录。完整安装包仍在时，也可进入该文件夹运行 sudo ./uninstall.sh。

若询问密码，输入服务器账号密码，不是平台登录密码。先记下终端显示的 “详细输出”日志路径。

2. 回答第一次询问：是否开始卸载 ​

看到 **“确定卸载 InduFrame 中心？”**和 [y/N]：

  • 输入 y 并回车：继续选择数据处理方式。
  • 输入 n 或直接回车：取消卸载，平台不会因此停用。

3. 回答第二次询问：是否删除数据 ​

看到 “是否同时删除平台数据与运行环境（数据库、对象库、配置、日志、程序目录）？”：

  • 要保留数据：输入 n 或直接回车。卸载会继续，停止服务并保留数据。
  • 确定删除数据：输入 y，进入最终确认。

两次回车的结果不同

第一次回车是取消整个卸载；已经确认卸载后，第二次回车会真正卸载服务并保留数据。

4. 只有永久删除时，输入最终确认 ​

终端会提醒“删除的数据无法恢复”，再要求 “输入 PURGE 确认”。

只有输入完全一致的大写 PURGE 才继续删除。输入其他内容或直接回车会取消本次卸载。

服务器原先就有运行环境时，还可能询问是否连它一起删除。它可能承载其他服务，默认保留；不了解用途时不要同意删除。

怎样确认卸载完成 ​

等终端明确给出最终结果，不要只凭网页打不开判断。

你的选择应看到的结果
取消提示“已取消卸载”，不算卸载完成
保留数据提示服务已卸载，配置、数据和运行环境按默认选项保留
删除数据提示服务、数据和平台程序已删除，并说明原有运行环境是否保留

保留数据卸载仍会清理部分安装设置。以后重装需要再次填写向导，自签名证书也会重新生成，请保管好原账号资料。

若提示采集数据已单独留存，或还有系统规则需处理，记下位置并交给维护人员。不要把删除成功理解为所有留存事项也已处理完。

没有成功时怎么办 ​

保留完整提示和“详细输出”日志，停止手工清理，联系维护人员。不要直接删除剩余目录，也不要在卸载未完成时马上重装。

更多现象见安装常见问题。

下一步 ​

保留数据卸载成功后，需要恢复使用时按保留数据后重新安装操作。已删除数据、需要全新安装时，从安装前准备开始。
