系统与安装要求 ​

本页用于准备 InduFrame v1.0 平台中心。如果只是登录已安装的平台，向组织管理员取得访问地址和账号即可，不需要自己安装服务器。

优先推荐 Ubuntu 24 ​

目前只测试了 Ubuntu 24，优先推荐这个系统。其他系统尚未测试，不作为已验证支持范围推荐。

安装脚本包含 Linux 环境检查，不表示所有 Linux 发行版都已经测试通过。不要把 Ubuntu 24 的安装、卸载结论直接用于其他系统；本页流程也不用于在 Windows 上安装平台中心。

安装前需要具备什么 ​

项目要求
安装包交付人员提供的完整包，版本和服务器架构匹配
系统账号具备系统管理权限，能够使用 sudo
系统服务服务器使用 systemd 管理服务，由维护人员确认
操作方式在能输入回答的终端中运行安装或卸载程序
系统盘余量至少 30 GiB，且至少保留磁盘总容量的 20%
独立数据盘余量另外使用数据盘时，该盘也同时满足上述两项余量
网络具备可用的 IPv4 网络；使用者能访问公共入口，平台管理员能访问管理入口所在网络

CPU、内存和业务存储容量应按工程规模、历史数据量和使用人数评估。本页不把磁盘最低余量作为实际业务容量承诺。

安装位置与数据盘 ​

向导默认填写程序父目录 /opt，实际程序目录为 /opt/induframe。选择其他程序存放位置，不会自动把运行数据迁移到那个磁盘。

如果需要专门安排数据盘，先与服务器维护人员确认磁盘及数据位置，再安装。不要以手工移动平台目录或删除原数据来调整存放位置。

地址、端口和证书 ​

  • 公共入口使用 HTTPS，默认端口 443；组织成员从这里登录。
  • 管理入口使用安装结果给出的内网 HTTP 地址，默认端口 18100，路径带 /admin/。
  • 两个端口不能相同，也不能与服务器上其他服务冲突。
  • 默认证书方式为 self-signed。使用者遇到信任提醒时，应由维护人员核对地址和证书后处理。
  • 使用已有证书的 provided 方式，需要维护人员预先核对文件、私钥及适用地址，不直接套用默认证书的验证结论。

完整离线包仍可能要求服务器事先具备必要的系统网络组件。完全离线时，请维护人员提前准备。客户服务器不需要另外安装 Docker，平台安装器会准备自身需要的运行环境。
