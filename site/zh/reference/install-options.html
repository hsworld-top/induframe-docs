安装参数 ​

本页供填写中心安装向导时查询。完整操作顺序见安装中心，环境条件见安装前准备。

当前为 v1.0，优先使用已测试的 Ubuntu 24；其他系统尚未测试。第一次安装可先跟随向导操作，需要查询限制时再回到本页。系统范围见系统与安装要求。

启动方式 ​

在完整安装包目录执行 ./install.sh，安装和完整更新均不需要参数。查看帮助使用 ./install.sh -h，其他参数不接受。已完成安装时会显示 1) 更新、2) 取消；输入 1 才更新，输入 2 或回车取消。更新沿用原安装设置，不重新填写下方初装字段。

向导字段 ​

字段默认值填写要求影响与示例
存放位置/opt可用的绝对目录，不能是根目录、受限系统路径、文件、符号链接路径或安装包内部自动追加 induframe；输入 /srv/platform，程序目录为 /srv/platform/induframe
公共访问地址或域名安装器识别的当前主机地址用户浏览器能够访问的地址；域名需要正确解析示例域名 platform.example.com 仅为说明，不能直接照填
公共访问端口4431–65535 的整数，不与管理端口重复或被其他服务占用当前向导固定使用 HTTPS；非默认端口需要写进访问地址
管理入口端口181001–65535 的整数，与公共端口不同管理地址由安装器选择内网 IPv4，使用安装结果打印的完整地址
平台超级管理员用户名admin3–50 个标识字符，以向导校验结果为准该账号用于管理入口，和组织内账号分开
TLS 模式self-signedself-signed 或 provided前者生成自签名证书；后者需要证书文件、私钥文件和可选 CA 文件的绝对路径
平台超级管理员初始密码无输入两次，8–72 字节，两次必须一致使用 ASCII 字符时一个字符为一个字节；中文等字符会占多个字节

密码长度

终端提示使用“字符”描述长度，当前校验实际按字节计数。建议使用 8–72 个 ASCII 字符设置初始密码；不要据提示推算多字节密码一定可接受。

账号与密码 ​

密码用于什么当前实际校验建议怎样设置
安装时的平台超级管理员8–72 字节，输入两次一致使用 8–72 个英文字母、数字或半角符号
首次设置时重置组织管理员密码1–72 字节，不能全为空白，输入两次一致同样建议使用 8–72 个英文字母、数字或半角符号

中文等字符占用多个字节；不要按屏幕显示的字符个数推算是否符合限制。上表区分实际校验和推荐写法，两类账号的密码分别保管。

证书选择 ​

self-signed 用于由维护人员核对并建立浏览器信任的环境。浏览器提示证书不受信任时，先核对证书和访问地址，不以关闭证书校验代替处理。

provided 需要证书、私钥匹配，证书在有效期内，信任链有效，并同时覆盖公共访问地址和服务器内网仓库地址。该分支及不同证书环境需由交付人员单独确认适用性。

入口形式 ​

入口地址形式默认端口
公共入口https://<公共地址>:<公共端口>/443
管理入口http://<内网地址>:<管理端口>/admin/18100

尖括号内容是占位说明，不是可直接访问的地址。默认 HTTPS 端口在浏览器中可以省略；仍以安装结果给出的地址为准。

安装后的材料 ​

材料用途
完整原安装包保留版本与完整性材料，用于经确认的同包重新安装
安装结果打印的两个入口分别交付给平台管理员和组织成员
安装终端给出的日志路径查询安装阶段、错误及原因；默认程序目录下为 logs/install-*.log
程序目录中的 uninstall.sh通过终端确认卸载范围
