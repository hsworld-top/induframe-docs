常用术语解释 ​

不需要先背下所有词。第一次接触平台，先看几个基本名词；操作中遇到不懂的词，再按本页分类查找，也可使用网站搜索。

这里解释“词是什么意思”，不代表所有配置、协议或运行组合都已经通过验证。具体操作以对应指南和当前交付范围为准。

平台、工程与账号 ​

术语普通话解释
平台中心提供组织管理、工程配置、开发和运维入口的平台服务；不是每个工程的页面
组织团队的工作范围，用来管理成员和工程
工程某个应用的源码、数据配置、身份和相关资料的集合
组织账号登录组织工作台的账号，用于开发、管理或运维
工程用户工程页面自己的用户，与组织账号分开
角色把一类使用者需要的权限归在一起；组织角色与工程角色用途不同
权限允许查看、调用或修改哪些内容；知道地址或路径不等于获得权限

详见入口与账号及工程用户与角色。

数据与取值 ​

术语普通话解释
数据点工程中可被引用的一项数据定义，可以代表一个值或一份结果
接入源工程连接数据库、消息服务或接口等数据来源的配置入口
工业采集通过相应协议从工业设备读取数据的配置与运行工作
变量给需要使用的一项数据起的名字；在不同模块中可能指采集变量或脚本里的数据点引用
查询按条件向数据服务取结果的规则，不一定会修改原数据
SQL向数据库描述“查什么或做什么”的语言；有些语句会修改甚至删除数据
字段一条记录或一个对象里的某项内容，例如温度、名称或时间
路径程序和配置准确引用某个点或对象时使用的标识，应从实际界面复制
输出 Key一项输出在配置中的标识，不是 API 密钥；修改它可能影响输出路径和引用
数据类型值的形态，例如数字、文本、布尔值、对象或数组
布尔值只有 true/false 两种值，常用于开关或是否成立
对象、数组对象按字段组织内容，数组按顺序组织多项内容，不等于一个普通数字
JSON常见的结构化数据文本格式，能表达对象、数组、数字和文本等内容
当前值本次读取到或最近取得的结果，需要连同来源、质量和时间一起判断
数据质量表示读取正常、失败、陈旧、未知或配置预览等状态，不是设备精度保证
时间戳标记某个事件或数值时间的记录；源时间和平台观测时间可能不同
采样、轮询采样是取得一份数据，轮询是按安排反复请求；有定义不等于一直在采样
默认值缺少某类实际输入时用于约定用途的值；开发默认值不能证明现场读通
历史记录过去已经保存的样本或事件，不等于当前值，也不等于完整备份
保留期计划保留历史数据多久，可能影响后续清理和能查询的时间范围

详见什么是数据点、SQL 数据点和历史存储。

计算与报警 ​

术语普通话解释
计算单元用输入数据和逻辑产生新结果或执行获准业务动作的一项配置
参数一次调用交给逻辑的输入，不一定来自设备采样
触发什么时候执行，例如手动、按周期、数据变化或条件成立
试运行对保存后的计算逻辑做开发检查；返回结果不等于写入输出数据点
报警规则描述什么情况下触发、怎样恢复以及如何通知的配置
活动报警运行中尚处于活动状态的报警实例，不是规则列表的一行定义
阈值判断条件的边界，例如温度高于某个值
死区在阈值附近留出判断范围，减少来回切换；不是简单忽略所有小数值
触发延时条件满足后还需持续多久才进入报警
清除延时恢复条件满足后还需持续多久才退出报警，单位按当前字段看
通知渠道报警消息送到哪里的配置；渠道测试和真实条件触发要分开验证
试算用提供的样本检查报警条件及状态变化，不是现场报警或通知送达证明

详见计算、报警和联动示例。

应用开发与 AI ​

术语普通话解释
源码决定应用页面和逻辑怎样工作的程序文件
模板、技术栈模板是初始工程内容，技术栈是工程采用的开发工具与语言组合
开发环境提供 AI 助手、编辑器和预览等开发工具的工作空间
页面预览检查开发内容的画面，不是已经上线的正式应用
AI 模型提供理解与生成能力的服务，不等于整个工程或平台
Provider提供模型接口的服务商或自定义服务配置
API Key调用服务使用的密钥，不是普通名称，不应写入聊天或公开文件
会话一段可以继续的交互记录；删除会话不等于撤销工程修改
工程上下文供 AI 理解当前工程的数据点、角色、计算、报警、资源等资料摘要
上下文压缩把较长对话整理成摘要，可能需要重新核对重要细节，不是备份
技能可复用的任务说明和资料，不是模型，也不会自动增加账号权限

详见AI 助手及AI 成果核对。

版本、部署与运维 ​

术语普通话解释
运行环境在运维中组织运行节点、基础服务、部署与访问安排的范围
节点平台登记的一台实际服务器或虚拟机，按资格承担任务
基础服务为运行提供存储、消息、对象文件和访问等能力的服务
运行引擎执行工程数据访问、计算或报警等工作的软件服务，不是物理服务器
构建将工程内容准备成可运行制品的过程，成功不等于业务已验收
工程版本固定一份工程内容，方便选择和追溯，不同于产品版本号
快照固定某个时刻的一份内容，之后修改开发内容不会自动改变它
发布在此处通常指创建可用于后续部署的工程版本，不等于所有环境立即更新
部署将选定内容安排到目标环境和节点运行
更新部署明确提交新的内容或版本来替换目标部署，需要核对影响
重启重新启动已有运行服务，不自动更新源码或版本
重新部署重下发当前制品，不自动构建最新开发内容
已受理请求已经进入处理，不等于任务完成
健康、就绪某项服务满足相应检查条件，不代表所有页面、设备和业务都通过验收
观测、指标过期观测是收到的状态或资源信息；过期说明不能直接用它确认当前情况
高可用需要实际故障容忍与恢复能力；多台节点本身不等于已经具备

详见运行环境和节点、发布版本和运行排查。

服务器、资源与安装 ​

运维是观察应用和服务器状态、处理异常、安排更新与维护的工作，不只是查看一个绿色图标。

术语普通话解释
服务器主要用于持续提供应用或数据服务的计算机，不是某个网页或账号
操作系统管理计算机资源并运行软件的基础系统，例如 Ubuntu；不是工程模板
CPU 架构处理器采用的指令体系，例如 x86-64、ARM64，安装包要与实际系统和架构匹配
虚拟机在物理计算机上划分出来运行操作系统的机器实例，不等于平台里新建一个运行环境
CPU执行计算和指令的处理器；用量高可能影响处理速度，但不能只凭一项指标判断故障
内存程序运行时使用的工作空间，不等于长期保存数据的磁盘
磁盘保存程序、文件和数据的存储空间；容量、剩余空间和运行内存是不同指标
节点代理安装在节点上、负责与平台联系并执行获准管理工作的程序，不是组织成员账号
心跳节点按安排向平台报告状态的信号，不代表全部业务和驱动都正常
终端输入命令并查看文字结果的操作窗口，不等于工程的最终使用页面
脚本按步骤执行任务的一组程序指令，运行前要确认来源和影响
sudo在具备授权时以系统管理权限执行命令的方式，不是平台账号或平台密码
离线安装包主要安装材料随包提供，仍需按说明检查系统、基础依赖和网络条件
补丁包面向明确版本和范围的更新材料，不应当成完整安装包使用
备份保存可用于恢复的数据和配置副本，并确认能实际恢复；工程导出或保留数据卸载不是完整备份
卸载停止并移除相应程序或服务，是否删除数据取决于所选方式，不等于普通重启

准备安装时继续看系统与安装要求，不要从名词解释推断硬件容量或恢复能力已经满足。

地址、协议与接口缩写 ​

术语普通话解释
IP 地址、域名找到网络服务的位置标识；域名是便于记忆的名字，仍需正确指向目标
DNS把域名解析到相应网络地址的服务，不会自动开放端口或授予权限
端口同一台主机上区分不同网络服务的号码，不能随意占用别的服务端口
TCP、UDP两种不同的网络通信方式；允许同一个号码的 TCP 连接，不代表 UDP 也已允许
防火墙、UFW控制哪些网络连接可以通过；UFW 是 Ubuntu 上常见的防火墙管理工具
安全组云服务器外侧的一层网络规则，与服务器里的防火墙需要分别检查
入站、出站别人连接当前服务器叫入站，当前服务器向外连接叫出站
网段、CIDR表示一组地址的范围；/32 通常表示一个 IPv4 地址，不是一组端口
HTTPS、TLS用于加密网络连接并结合证书核验身份，不等于业务账号已经有权限
证书、私钥用于证明服务身份的配套材料；私钥必须安全保管，不应公开
Token一种访问凭据，可能有期限与权限范围，不是可以公开分享的普通地址
API程序之间请求数据或操作的约定接口，仍需要符合授权与参数要求
SDK帮助开发者调用平台能力的工具，不等于已经做好的业务页面
MCP让获准开发工具连接工程资料或能力的一种工具接入约定，以产品开放范围为准
Broker接收、转发消息的服务端，不是某一条具体消息
Topic消息发布或订阅的主题标识，不等于数据点完整路径
QoS消息传输的服务级别约定，不能直接当成整个业务链绝不丢失或重复的保证
TTL一项内容或凭据的有效时长，单位和到期行为按具体字段确认
Schema在数据库场景常指表等对象的组织范围，在数据校验场景可能指结构规则
K3s平台运行基础设施使用的软件之一；普通使用者不必先掌握其管理命令
容器在服务器上承载程序的一种运行方式，不是另一台物理服务器，也不等于运行环境

术语用于帮助理解，不授权执行真实接口、修改设备或开放网络。需要操作时，继续按对应模块的步骤、前提和安全提示处理。
