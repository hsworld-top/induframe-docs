导入工程 ​

迁移或接收已有工程时，用工程归档文件导入，而不是在应用开发里上传压缩包。本页说明入口、支持的格式和常见问题。

开始前 ​

  • 已登录并打开左侧“工程管理”，且账号有管理工程的权限。
  • 手上是 .ifproj（单个工程）或 .ifbatch（批量包）归档文件。普通 .zip 不能用于导入。

入口 ​

  1. 打开左侧“工程管理”，进入工程概览。
  2. 在列表上方的工具栏里找到导入工程按钮（上传图标，悬停显示“导入工程”），点击后选择归档文件。
  3. 选择完成后先进入导入预览，确认无误再执行导入。

支持的文件 ​

文件说明选择方式
.ifproj单个工程的完整归档，包含工程信息、配置与工作区源码可一次多选多个，逐个预览后导入
.ifbatch批量分发包，内含多个工程一次只能选一个，且不能与其他文件混选

普通 .zip、旧 .json 归档和文件夹都不接受：压缩包请先按归档格式导出为 .ifproj，旧 JSON 归档已停用。

预览并确认 ​

  • 预览会显示工程名称、包体积、条目数、配置行数、运行用户数；批量包还会显示包含的工程数量。
  • 确认内容后执行导入；导入过程中不要重复点击。
  • 批量包部分成功时，列表会刷新显示已导入的工程，结果提示同时列出成功和失败项。

常见问题 ​

  • 提示“请选择 .ifproj 或 .ifbatch 工程归档文件”：选错了文件，换成归档文件重试。
  • 提示“旧 JSON 归档已停用，请使用 .ifproj”：把旧归档按当前格式重新导出后再导入。
  • 提示“未找到 project.json / 工程数据格式不正确”：归档不完整或已损坏，请重新导出或向交付方索取完整包。
  • 导入后看不到工程：确认当前组织和权限，并刷新工程列表。

与上传文件的区别 ​

  • 导入工程：用 .ifproj / .ifbatch 创建一个完整工程，出现在工程列表里。
  • 上传文件：在已有工程的应用开发里上传 .zip 等普通文件，只写入该工程的工作区，不会创建新工程；见在应用开发中上传文件。

下一步 ​

导入完成后打开工程，在应用开发里继续编辑或让 AI 助手修改；账号与入口说明见登录与退出。
