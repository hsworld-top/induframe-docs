查看和上传工程文件 ​

需要把图片、资料等文件交给当前工程使用时，可以进入工程的资源页。这里的文件存放在工程对象库，与编辑器中的源码文件分开管理。

开始前，你需要已经能打开一个工程的“应用开发”，并具备相应操作权限。如果工程还不能打开，先请工程管理员准备好工程，再从本页开始。

1. 打开资源页 ​

  1. 从公共入口登录组织，进入“工程管理”。
  2. 找到要操作的工程，打开“应用开发”。
  3. 在工程工作区选择 “资源”。
  4. 先核对工程名称，再查看文件列表。

列表显示名称、类型、大小和更新时间。没有文件时，页面会提示“当前目录还没有对象库文件，请点击‘上传文件’开始。”。

文件多时，可在列表底部翻页或调整每页条数。需要重新核对内容时，点击“刷新”。不要因为只看到当前页，就认为整个工程只有这些文件。

2. 上传一个文件 ​

  1. 点击 “上传文件”，从电脑选择准备好的文件，一次选择一个。
  2. 留意“正在上传”的进度，等待操作结束。
  3. 确认列表出现该文件，核对名称、大小和更新时间。
  4. 点击“刷新”，再次确认文件仍在。

传输显示 100% 后，还要等待操作结束并确认列表结果。操作未结束时，不要连续点击上传。

需要中止时，在进度区域点击 “取消上传”。等当前操作结束，再刷新列表核对结果；需要继续时，重新选择文件上传。

第一次练习可用一份不含敏感信息的小文件。较大文件的限制请先与工程管理员确认，以当前页面和交付说明为准。

3. 打开文件或复制地址 ​

点击文件名或该行的 “打开”，可查看对应文件。浏览器怎样显示取决于文件类型，不是所有文件都会像图片一样直接预览。

取得地址时：

  1. 点击该行的 “复制资源地址”。
  2. 看到复制成功提示后，将地址粘贴到需要的位置。
  3. 如果出现复制失败对话框，可选中其中的完整地址手动复制，或点击“再次复制”。

资源地址仍需要登录和相应工程权限，不是公开分享链接。 不要通过发送地址来代替为对方分配访问权限。

4. 不再需要文件时移除 ​

先确认工程、文件名和用途，避免影响仍在使用它的页面。需要保留的文件，应先保存好副本。

  1. 点击该行的 “移除”。
  2. 在“移除文件”对话框核对文件名。
  3. 不确定时点击“取消”；确认不再需要时才点击 “确认移除”。
  4. 等操作结束，刷新列表，确认文件不再显示。

移除某页最后一个文件后，列表可能返回前面的页，请先检查页码，不要误以为其他文件也被删除。不要假定移除后一定能从回收站找回。

操作没成功时怎么办 ​

看到的情况先做什么
不能打开工程或资源页核对组织和工程，联系工程管理员确认权限与开发环境状态
上传中断或失败等当前操作结束，刷新列表核对文件是否已出现，再决定是否重试
打开地址时要求登录使用有该工程权限的账号登录，不把地址当成免登录链接
复制失败从对话框手动复制完整地址，或点击“再次复制”
移除失败或结果不明确保留提示，刷新列表确认实际状态，不连续重复确认

仍有问题时，记录工程名称、操作、发生时间和页面提示，交给维护人员。不要提供密码、登录 Cookie 或含敏感信息的文件。

下一步 ​

确认文件操作结果后，再按工程用途使用这些资料。上传或移除开发资料不会替你完成工程发布；需要更新正在使用的工程时，请按交付安排进行发布与核对。
