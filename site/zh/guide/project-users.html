管理工程用户 ​

工程用户用于工程页面自己的登录，不是登录组织工作台的账号。本页维护工程的初始用户预设；正式运行的用户与策略需要随工程发布、更新安排同步，不要把预设保存当成所有部署立即生效。

修改预设需要工程创建者或组织管理员权限。其他成员看到只读提示时，请联系有权维护此工程的人，不要换用他人账号。

1. 打开用户预设 ​

  1. 从公共入口登录组织，进入 “工程管理”。
  2. 找到目标工程，打开 “用户预设”。
  3. 核对对话框中的工程名称，选择 “用户管理”。

不要转到组织的“用户管理”添加同名账号，那不会自动成为这个工程的页面用户。

2. 准备角色并创建用户 ​

没有可选角色时，先按管理工程角色创建角色，再回来添加用户。

  1. 点击 “创建用户”。
  2. 填写“登录账号”、显示名称和“初始密码”，按页面的工程密码要求准备口令。
  3. 选择该用户需要的角色，核对已选角色数量。
  4. 保存，等待“用户创建成功”。
  5. 回到列表搜索该账号，刷新或重新打开后确认资料与角色正确。

按最小需要分配角色，不为了方便给所有人使用内置管理员。通过安全方式交付密码，不把口令放进普通文档或聊天群。

3. 修改资料、角色和状态 ​

使用用户行的“编辑”调整资料，使用 **“分配角色”**调整绑定。提交后核对角色列表，不把“创建了角色”当成已经分配给用户。

需要暂停使用时，先核对账号并通知使用者，再使用 “停用”；恢复时使用“启用”。当前页面编辑的是预设，正式运行中的会话和权限还需按部署更新安排验证。

内置 admin 用户受到保护，不允许停用或删除。不要通过删除角色、直接改文件等方法绕过保护。

4. 忘记密码时 ​

选择正确用户的 “重置密码”，输入新密码及确认新密码，满足当前工程密码要求后点击 “确认重置”。等待“密码重置成功”，再安全交付。

不要把组织管理员重置密码、工程用户重置密码和预览中的管理员口令设置混为一项操作。预览身份的用途见页面预览。

5. 删除前确认 ​

删除用户会同步移除该用户的角色分配。先核对工程和账号，再阅读确认提示；不确定时取消。

需要停用而不是删除时，优先选择停用。不要假设删除后还能恢复，也不要把删除预设当成所有已发布版本的身份清理已经完成。

怎样确认完成 ​

重新读取列表，核对用户、角色和状态；用合适的工程用户检查开发预览，并在部署更新后另外验证正式页面登录。出现失败或结果不明确时，保留提示并先核对，避免重复创建。
